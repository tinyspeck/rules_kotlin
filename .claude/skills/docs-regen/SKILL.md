# Regenerate the rules_kotlin API docs

`docs/kotlin.md` is generated by stardoc from `kotlin/jvm.bzl`, `lint.bzl`,
`core.bzl` and `repositories.doc.bzl` (the `//kotlin:stardoc` genrule). Never
edit it by hand.

1. Regenerate: `make docs.regen`, or on a Speck pod
   `scripts/speck_bazel.sh docs-regen`.
2. Check it matches: `bazel test //docs:are_docs_up_to_date_test`, or
   `scripts/speck_bazel.sh test //docs:are_docs_up_to_date_test`.
3. Read the `docs/kotlin.md` diff. It should reflect only the docstring or
   attribute changes you made; anything else means the stardoc version or an
   unrelated rule changed, which is worth calling out in the PR.
4. Commit `docs/kotlin.md` in the same commit as the Starlark change.
