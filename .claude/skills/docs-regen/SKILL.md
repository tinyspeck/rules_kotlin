# Regenerate the rule docs

`docs/kotlin.md` is generated by Stardoc from the Starlark docstrings and
checked by a test. Never hand-edit it.

## On a DevSpace Pod (Speck)

```sh
devspace/speck_bazel.sh docs-regen
devspace/speck_bazel.sh docs-check
```

## Elsewhere

```sh
bazel run //docs:write_docs   # regenerate
bazel test //docs/...         # check
```

## Notes

- Commit the regenerated file in the same commit as the docstring change.
- If the regenerated diff touches rules you didn't change, the branch was
  already stale; mention it in the PR instead of hiding it in your change.
