# ktlint

The builder's Kotlin sources are linted by `ktlint_test` targets generated by
`kt_bootstrap_library` (`src/main/kotlin/bootstrap.bzl`). Each library gets a
`<name>_ktlint_test` (tagged `ktlint`) and a `<name>_ktlint_fix`.

## On a DevSpace Pod (Speck)

```sh
devspace/speck_bazel.sh ktlint-check
devspace/speck_bazel.sh ktlint-fix
devspace/speck_bazel.sh run //src/main/kotlin/io/bazel/worker:worker_ktlint_fix   # one package
```

`ktlint-fix` runs `//:ktlint_fix_all`.

## Elsewhere

```sh
bazel test //... --test_tag_filters=ktlint --build_tests_only --test_output=errors
bazel run //:ktlint_fix_all
```

## Notes

- Rules come from the root `.editorconfig`; don't add per-file suppressions to
  get a check passing.
- A new `kt_bootstrap_library` needs adding to `//:ktlint_fix_all` in the root
  `BUILD`.
- Run the fix, then the check: some violations have no auto-fix.
